# apps/web

클라이언트. 서버 스냅샷을 받아 그리고, 틱 사이를 보간한다.

## 실행

레포 루트에서:

```sh
pnpm install
pnpm dev            # :5173
```

이 디렉터리에서 `pnpm typecheck`, `pnpm test`, `pnpm build`.

개발 서버는 `/healthz`와 `/ws`를 `http://localhost:8080`(Go 서버)으로 프록시한다.
서버를 다른 포트로 띄웠다면 `SERVER_ORIGIN=http://localhost:9000 pnpm dev`.

프록시를 두는 이유는 클라이언트가 개발·배포에서 똑같은 상대 경로를 쓰게 하려는 것이다.
`ws://localhost:8080/ws` 같은 절대 주소를 코드에 적으면 배포 때 갈라진다.
